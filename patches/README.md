# Compiler and runtime changes

Only patches reproduced or justified for this game's original-speed baseline
belong here. They apply to the exact source revision in `vendor/manifest.json`.
Do not import adaptive timing, interpolation, multiplayer, or another game's
address hooks. Record a patch's trigger, test and limits in `research.md`, and
any reusable improvement in `ps2-web-re-pr.md`.

The first build candidate uses the pristine upstream compiler/runtime.
