# Generated game translation

Run `scripts/game/regenerate.py` with the supported private disc. Generated EE
units and any explicitly supplied recorded VU translation are written into the
chosen ignored translation workspace. `translation.json` records their hashes.

No translation from another game is used. The initial disc pass produced 167 EE
units. `manifest.json` retains the exact accepted generated file hashes and
generator provenance. This is compilation input, not proof of playable gameplay. The original
executable, recorded VU images and generated game code remain local.
